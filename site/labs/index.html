CyberSecurity_Lab

A collection of safe, self-contained simulations that reproduce the observable traces of common attacks — so defenders can practise detecting them with real tooling: Sysmon, EDR, Procmon, and Wireshark/tcpdump. These are detection-training simulations, not attack tools.

View on GitHub → The four labs
Why it is safe. Every lab keeps traffic on 127.0.0.1 by default (reaching another host needs an explicit --allow-lan, which permits private/lab ranges only — public addresses are always refused); does no source-IP spoofing and runs no real payloads; bounds workers, duration, and response sizes; and writes an events.jsonl answer key plus report and detect commands. Run them only on systems and networks you own or are authorized to test.

The four labs

Each folder is self-contained — the lab script, its tests, and a README. Stdlib-only Python 3.9+.

Gift-Card IR TCP 8765

A full intrusion story you can hunt end to end: a malicious lure, a payload, persistence, C2 beaconing, and staged exfiltration.

  • Lure → payload → persistence → C2 beacon → exfil
  • Persistence writes simulated Run-key + scheduled-task artifacts (never applied)
  • Optional real local host telemetry to hunt (opt-in)

DDoS TCP 8768

Volumetric and slow-rate denial of service, plus an HTTP/2 rapid-reset vector — each with a different detection signature to learn.

  • volumetric · cachebust · connflood · bodyflood
  • slowloris · rudy · slowread
  • rapidreset — HTTP/2 rapid reset (CVE-2023-44487)

Amplification UDP 8769

Why reflection/amplification works — a tiny query provokes a large response. Measure the factor safely (no spoofing, so it returns to you).

  • Protocol profiles: DNS · NTP · SSDP · memcached
  • Each pairs a query signature with a realistic factor + source port

Web-Attack TCP 8770

The traces web attacks leave in access logs and connection telemetry. The victim only logs what it receives — payloads are never executed or fetched.

  • credstuff · enum · inject · portscan
  • ssrf — cloud metadata / internal targets (logged, never fetched)
  • traversal — encoded path-traversal variants

Run it

Every lab follows the same serve → attack → run → report → detect → reset pattern.

# Requires Python 3.9+ (standard library only for the core labs)
cd gift_card_lab
py gift_card_lab.py run --announce --auto-serve   # play out a scenario
py gift_card_lab.py report                         # the answer key (timeline + IOCs)
py gift_card_lab.py detect                         # what to hunt for
py gift_card_lab.py reset                          # clean up
01

Run

Launch a scenario on loopback while your detection tooling is active.

02

Capture

Watch it with Sysmon, EDR, Procmon, or a Wireshark/tcpdump capture.

03

Compare

Check what your tools caught against the report answer key.
